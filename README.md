An interactive agricultural market price analysis and visualization project developed using Microsoft Power BI. This project transforms raw agricultural market data into meaningful insights through data cleaning, transformation, analytical measures, and interactive dashboards.

---

## 📌 Project Overview

Agricultural markets generate large amounts of data related to commodity prices, market locations, and arrival dates. Understanding this data manually can be time-consuming and challenging.

The **Agriculture Data Analytics & Visualization System** provides a Power BI-based analytical solution to explore agricultural commodity price patterns across different states, districts, markets, and commodities.

The project focuses on transforming raw data into clear visual insights that support better understanding of agricultural market behavior.

## 🎯 Objectives

* Analyze agricultural commodity market prices.
* Explore price variations across different states and markets.
* Understand commodity price trends over time.
* Clean and transform raw agricultural datasets.
* Create calculated measures using DAX.
* Develop interactive dashboards for data exploration.
* Present analytical insights through meaningful visualizations.

## ✨ Key Features

### 📊 Agricultural Price Analysis

Explore agricultural commodity prices across different markets and locations.

### 🗺️ State & Market Analysis

Analyze price distribution across states, districts, and markets.

### 📈 Trend Analysis

Explore commodity price changes over the available time period.

### 🔍 Interactive Filtering

Use slicers and filters to explore data by state, commodity, and market.

### 🧮 DAX-Based Measures

Calculate average, minimum, and maximum modal prices for analysis.

### 📉 Data Visualization

Present insights using charts, maps, and KPI visuals.

## 📂 Data Preparation & Transformation

The dataset contains agricultural market information such as:

* State
* District
* Market
* Commodity
* Price
* Arrival Date

### Data Cleaning

The data is prepared using Power Query to handle missing values, format fields, and improve data consistency.

### Data Transformation

Relevant fields such as arrival dates and commodity categories are transformed to support analysis.

### Data Analysis

DAX measures are created for:

* Average Modal Price
* Minimum Modal Price
* Maximum Modal Price

## 📊 Dashboard Analysis

The Power BI dashboard focuses on the following analytical areas:

### 1. Commodity Price Comparison

Compare agricultural commodity prices across different commodities to understand price differences.

### 2. State-wise Price Distribution

Explore agricultural price variations across different states.

### 3. Market-wise Price Analysis

Analyze market-level price information and compare different market locations.

### 4. Price Trend Over Time

Explore commodity price trends across the available time period.

### 5. Interactive Dashboard Exploration

Use slicers and filters to analyze agricultural market data based on selected states, commodities, and markets.

## 🚀 How to Use

* Microsoft Power BI Desktop
* Windows operating system

